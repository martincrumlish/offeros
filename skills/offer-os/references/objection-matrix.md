# Objection Matrix

Deep-mode copy must include 7+ real objections. Generic FAQ labels are not enough.

Each objection row must include:

- `objection`
- `answer`
- `beliefShift`

Cover these categories unless the offer makes one irrelevant:

- price
- time
- implementation
- fit
- trust
- proof
- refund / risk
- "is this just more information?"
- "will this work for my situation?"

Answers should change belief, not merely reassure. Do not use generic questions like "What is this?" or "How does it work?" as the objection matrix.
