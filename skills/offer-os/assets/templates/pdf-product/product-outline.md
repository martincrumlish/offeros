# PDF Product Outline

## Cover

- Product title
- Specific promise
- Audience
- Brand/logo

## Quick Start

- What this product helps the buyer do
- How to use it in the first 10 minutes
- What to complete first
- What result they should have by the end

## Depth Target

- Up to $29: 18+ pages, 4+ modules, 5+ action surfaces.
- $30-$99: 25+ pages, 5+ modules, 8+ action surfaces.
- $100+: 35+ pages, 6+ modules, 10+ action surfaces.

Action surfaces are worksheets, checklists, templates, scripts, examples, scorecards, calculators, planners, audits, or cards.

## Module 1: Diagnose

- Current-state checklist
- Problem scorecard
- Mistake map
- Example diagnosis

## Module 2: Decide

- Decision framework
- Good/better/best examples
- Prioritization table
- Buyer fill-in worksheet

## Module 3: Build

- Templates
- Scripts
- Prompts
- Swipe examples
- Completed example

## Module 4: Implement

- Step-by-step action plan
- Time estimate
- Common blockers
- Fixes and fallback paths

## Final Checklist

- Completion checklist
- Quality check
- Next step
- CTA or support path

## Required Buyer Value

Include both completed examples and blank buyer-fillable versions for the core worksheet/template. Render-check the final PDF pages before delivery.
